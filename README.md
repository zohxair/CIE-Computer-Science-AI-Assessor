# ⚡ CIE Computer Science AI Assessor v4.0

An immersive, high-fidelity web application engineered to audit, fix, and transpile pseudocode according to the **Cambridge International AS & A Level Computer Science (9618)** and **O Level (2210)** syllabi. Powered by cutting-edge open-source LLMs via the Hugging Face Inference API, this tool features a cyberpunk aesthetic, glassmorphic layout primitives, and real-time diagnostic pipelines.

## 🌌 Key Features

### 1. 📝 Pseudocode Structural Auditor & Repair Matrix
- **Syllabus-Compliant Guardrails:** Validates against strict Cambridge syntax conventions (e.g., uppercase keywords like `IF-THEN-ELSE`, `WHILE-ENDWHILE`, and block assignments with `<-`).
- **Variable Typing Check (9618 Premium):** Assesses the deployment of explicit, strongly-typed variables (e.g., `DECLARE <identifier> : <data_type>`) at the top of code scopes.
- **Auto-Refactoring Engine:** Renders an optimized, error-free version of your logic in the terminal panel instantly.

### 2. 🔄 Native Python Transpiler
- Translates dynamic, native Python code modules directly into highly precise, examination-ready Cambridge blueprint pseudocode structures.

### 3. 🎯 Exam Challenge Vector Matrix
- Generates algorithmic challenge prompts on demand, mapped closely to real parallel-array structures, input validations, and searching/sorting matrix criteria.

### 4. 👑 Zohair's Domain (The Glaze Machine)
- An exclusive, cinematic sci-fi workspace featuring an interactive **Particle Control Matrix console** and a dynamic, quantum-neon animated status feed. Engaging the stream core triggers high-fidelity text feedback streams processing complex computer science parameters (like `1024 MiB Buffer handling`).
